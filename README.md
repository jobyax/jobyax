# Jobyax — Software Security Engineer

> Mon combat contre la cybercriminalité en RDC.

J'identifie, j'analyse et je documente les menaces numériques en RDC : vulnérabilités applicatives, arnaques et escroqueries. Je préviens les victimes avant qu'elles ne perdent leur argent ou leurs données, et je ne publie que ce qui est vérifiable.

## Domaines de spécialisation

- **Analyse de vulnérabilités** : analyse technique, cause racine, impact et correctifs.
- **Arnaques en RDC** : phishing, faux investissements, usurpation d'identité, fraude aux paiements.
- **Enquêtes et cybercriminalité** : recoupement de sources publiques pour établir les faits.
- **Hacking éthique** : tests autorisés pour trouver les faiblesses avant exploitation.

## Méthodologie

- **Identifier → Vérifier → Documenter → Publier** : de la collecte du signalement à l'alerte des personnes concernées.
- **Règles** : autorisation écrite avant tout test, périmètre et durée définis, aucune exploitation de données personnelles, notification avant publication.
